# ES6 Data Manipulation

This project covers ES6 data manipulation features in JavaScript, including
arrays, typed arrays, sets, maps, and weak maps.

## Learning Objectives

- Use `map`, `filter`, and `reduce` on arrays.
- Work with typed arrays.
- Use `Set`, `Map`, and `WeakMap` data structures.

## Requirements

- Ubuntu 20.04 LTS
- Node.js 20.x.x
- npm 9.x.x
- Files use the `.js` extension
- All functions are exported
- Code is tested with Jest
- Code is linted with ESLint
