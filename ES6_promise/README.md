# ES6 Promises

This project covers JavaScript promises, async functions, and error handling.

## Learning Objectives

- Explain how promises work and why they are useful.
- Use `then`, `catch`, `resolve`, `reject`, `all`, `allSettled`, and `race`.
- Handle errors with `throw`, `try`, `catch`, and `finally`.
- Use `await` inside async functions.

## Requirements

- Ubuntu 20.04 LTS
- Node.js 20.x.x
- npm 9.x.x
- Files use the `.js` extension
- All functions are exported
- Code is tested with Jest
- Code is linted with ESLint
